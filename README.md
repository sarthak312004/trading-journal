# 📈 Trade Commit

Trade Commit is a trading journal and performance analyzer built with HTML, CSS, and JavaScript.

## Features

* Add, update, delete, and search trades
* Store trade details using objects and arrays
* Track trade history and notes
* Analytics dashboard with:

  * Net P/L
  * Total Trades
  * Win Rate
  * Average Win
  * Average Loss
  * Best Performing Asset
  * Poor Performing Asset
* Responsive user interface

## Tech Stack

* HTML
* CSS
* JavaScript

## Learning Objectives

* DOM Manipulation
* Event Handling
* Arrays & Objects
* CRUD Operations
* Data Analysis
* Searching & Filtering
* Responsive Design
