# Trading_journal

A beginner-friendly JavaScript project designed to simulate a real-world trading journal. The application allows users to record trades, calculate profits and losses, monitor win rates, track trading streaks, and generate performance statistics.

The goal of this project is to strengthen core JavaScript concepts such as arrays, objects, functions, loops, conditionals, sorting, searching, and data analysis while solving a practical problem faced by traders.

## Features

* Add, update, and delete trades
* Calculate profit/loss for individual trades
* Track total profitability
* Analyze win and loss rates
* Find best and worst trades
* Monitor winning and losing streaks
* Sort and search trade records
* Generate trading performance summaries

## Tech Stack

* JavaScript (Vanilla JS)
* Git & GitHub

## Learning Goals

* Data Structures (Arrays & Objects)
* Functions and Modular Code
* Loops and Conditional Logic
* Date Handling
* Sorting and Searching
* Performance Analysis and Statistics
